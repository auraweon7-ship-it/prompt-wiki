# AI 프롬프트 위키 · Prompt Wiki KR

실무에서 바로 쓸 수 있는 한국어 AI 프롬프트 **1,048개**를 **36개 카테고리**로 정리한 카탈로그입니다.
Claude · ChatGPT · Gemini 등 대부분의 LLM에 그대로 붙여넣어 사용할 수 있습니다.

런타임 의존성은 Express 하나뿐이고, 콘텐츠와 화면 전체가 `index.html` 한 파일에 들어 있습니다. 빌드 단계가 없습니다.

## 무엇이 들어 있나

- **프롬프트 1,048개** — 평균 955자. 전부 같은 6요소 구조(역할 / 맥락 / 작업 단계 / 출력 형식 / 예시 / 불확실성 처리)로 작성
- **7개 그룹 · 36개 카테고리** — 비즈니스·일 / 콘텐츠·창작 / 비주얼·미디어 / 개발·데이터 / AI·자동화 / 성장·생산성 / 라이프
- **예제 모드** — 프롬프트마다 `[ ]` 자리표시자를 실제 값으로 채운 예시를 함께 제공
- **검색 · 카테고리 필터 · 정렬 · 원클릭 복사 · 모바일 반응형**

## 사용법

1. 상단 검색창에 키워드를 넣거나, 왼쪽에서 카테고리를 고릅니다.
2. 카드를 눌러 프롬프트 전문을 확인합니다.
3. `[ ]`로 표시된 자리표시자를 본인 상황에 맞게 바꾼 뒤 복사해 사용합니다.

### 화면 구성

| 위치 | 내용 |
| --- | --- |
| 상단바 | 검색, 마지막 업데이트일, 방문 횟수, 전체 프롬프트 수 |
| 왼쪽 사이드바 | 7개 그룹으로 묶인 36개 카테고리와 각 카테고리의 프롬프트 수 |
| 목록 상단 | `추천순` / `이름순` 정렬 |
| 카드 하단 | `예제` 버튼과 `복사` 버튼 |
| 카드 클릭 | 프롬프트 전문 모달 — `원본` / `예제 적용` 전환과 복사 |

### 예제 모드

각 카드의 **예제** 버튼을 누르면 자리표시자가 실제 예시 값으로 채워진 상태로 모달이 열립니다.
모달 안에서 **원본 / 예제 적용**을 전환할 수 있고, 복사 버튼은 현재 보고 있는 모드의 텍스트를 복사합니다.

| 표시 | 의미 |
| --- | --- |
| 주황색 `[주제]` | 사용자가 채워야 하는 자리표시자 |
| 초록색 값 | 예제 모드에서 채워진 예시 값 |
| 예제 모드에서도 주황색인 `[확인 필요]` `[법무 검토 필요]` `[가설]` | AI가 출력에 남기도록 지시하는 마커. 사실 확인이나 전문가 검토가 필요한 지점을 표시하므로 채우지 않습니다 |

1,048개 중 1,011개에 예제 값이 들어 있고, 치환되는 값은 모두 4,928개입니다.
나머지 37개는 사용자가 채울 자리표시자가 없는 프롬프트로, 예제 버튼이 비활성 상태입니다.

## 로컬 실행

```bash
npm install
```

```bash
npm start
```

`http://localhost:3000` 에서 열립니다. 포트는 `PORT` 환경변수로 바꿀 수 있습니다.

```bash
PORT=8080 npm start
```

`index.html`은 정적 파일이므로 서버 없이 브라우저로 직접 열어도 동작합니다. `npm start`는 배포 환경과 같은 방식으로 확인하고 싶을 때 사용하세요.

## 배포

빌드 산출물이 없으므로 두 가지 방식 모두 가능합니다.

- **정적 호스팅** — GitHub Pages, Netlify, Vercel, S3 등에 `index.html` 하나만 올리면 됩니다.
- **Node 호스팅** — Render, Railway, Fly.io 등에서 `npm start`로 실행합니다. `server.js`가 `PORT`를 읽고, 모든 경로를 `index.html`로 되돌려 줍니다.

## 구조

```
index.html   콘텐츠 · 스타일 · 스크립트가 모두 들어 있는 단일 파일
server.js    Express 정적 서버
package.json
```

프롬프트 데이터는 `index.html` 안의 `PROMPTS` 배열에 있습니다. 각 항목의 형태는 다음과 같습니다.

```js
{
  cat: 'mkt',                    // 카테고리 id
  title: '블로그 포스트 초안',
  desc: '검색 유입을 노린 블로그 글 구조',
  prompt: `당신은 ...`,           // 프롬프트 전문
  ex: { '주제': '뉴스레터 오픈율을 올리는 제목 쓰기' }  // 예제 값 (선택)
}
```

`ex`는 자리표시자 텍스트를 키로 갖는 맵입니다. 예제 모드는 `prompt` 안의 `[키]`를 이 값으로 치환하고, `ex`에 없는 자리표시자는 그대로 둡니다. 그래서 `[법무 검토 필요]` 같은 마커는 `ex`에 넣지 않습니다.

카테고리와 그룹은 같은 파일의 `CATEGORIES`, `GROUPS` 배열에 있습니다.

## 프롬프트 추가하기

1. `index.html`의 `PROMPTS` 배열에 항목을 추가합니다.
2. `cat`에는 아래 표의 카테고리 id를 넣습니다.

4. 사이드바의 카테고리별 개수와 상단의 전체 개수는 배열에서 자동으로 계산되므로 따로 고칠 필요가 없습니다.

## 프롬프트 구조

모든 프롬프트는 OpenAI · Anthropic · Google · Microsoft의 프롬프트 엔지니어링 가이드가 공통으로 강조하는 6요소를 갖추고 있습니다.

| 요소 | 섹션 | 하는 일 |
| --- | --- | --- |
| 역할 | `■ 역할` | 어떤 사람으로서 답할지와 그 사람의 원칙 |
| 맥락 | `■ 입력` | 상황·대상·제약을 채워 넣는 자리 |
| 작업 단계 | `■ 구성` · `■ 작성 순서` 등 | 할 일을 번호로 분해 |
| 출력 형식 | `■ 출력` | 표·코드 블록·분량 등 결과의 형태를 못 박음 |
| 예시 | `■ 예시` | 채워진 입력 하나와 기대 출력 발췌 |
| 불확실성 처리 | `■ 규칙` | 지어내지 말고 `[확인 필요]`로 표시 |

## 프롬프트를 쓸 때의 원칙

카탈로그에 포함된 프롬프트는 다음 기준을 지키도록 작성했습니다.

- 법률 · 세무 · 노무 관련 프롬프트는 `[법무 검토 필요]` 같은 마커를 남기고, 전문가의 조언을 대체하지 않는다고 명시합니다.
- 건강 관련 프롬프트는 진단을 내리지 않으며, 전문가를 찾아야 하는 시점을 함께 안내합니다.
- 이미지 프롬프트는 실존 인물의 초상과 특정 작가 화풍의 모방을 금지합니다.
- 마케팅 프롬프트는 수치 조작, 후기 조작, 허위 희소성 표현을 금지합니다.
- 개인정보를 다루는 프롬프트는 최소 수집과 동의 절차를 요구합니다.

## 알아두면 좋은 점

- **외부 리소스는 웹폰트뿐입니다.** Pretendard는 jsDelivr, JetBrains Mono는 Google Fonts에서 불러옵니다. 네트워크가 없으면 시스템 폰트로 폴백되고 나머지 기능은 그대로 동작합니다. 추적 스크립트나 분석 도구는 넣지 않았습니다.
- **상단의 방문 횟수는 서버 집계가 아닙니다.** `localStorage`에 저장되는 브라우저별 방문 횟수라서, 다른 기기나 시크릿 창에서는 값이 다릅니다.
- **마지막 업데이트일은 수동으로 갱신합니다.** `index.html`의 `updateDate` 값을 직접 고쳐야 합니다.
- **다크 테마 전용입니다.** 라이트 테마와 테마 전환 기능은 없습니다.
