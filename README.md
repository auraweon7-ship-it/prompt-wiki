# AI 프롬프트 위키 · Prompt Wiki KR

실무에서 바로 쓸 수 있는 한국어 AI 프롬프트 **1,038개**를 **36개 카테고리**로 정리한 카탈로그입니다.
Claude · ChatGPT · Gemini 등 대부분의 LLM에 그대로 붙여넣어 사용할 수 있습니다.

의존성은 Express 하나뿐이고, 콘텐츠와 화면 전체가 `index.html` 한 파일에 들어 있습니다. 빌드 단계가 없습니다.

## 무엇이 들어 있나

- **프롬프트 1,038개** — 평균 534자, 역할·입력·작업 단계·출력 형식·주의사항을 갖춘 구조화된 프롬프트
- **7개 그룹 · 36개 카테고리** — 비즈니스·일 / 콘텐츠·창작 / 비주얼·미디어 / 개발·데이터 / AI·자동화 / 성장·생산성 / 라이프
- **예제 모드** — 프롬프트마다 `[ ]` 자리표시자를 실제 값으로 채운 예시를 함께 제공
- **검색 · 카테고리 필터 · 원클릭 복사 · 모바일 반응형**

## 사용법

1. 카테고리를 고르거나 검색으로 프롬프트를 찾습니다.
2. 카드를 눌러 전문을 확인합니다.
3. `[ ]`로 표시된 자리표시자를 본인 상황에 맞게 바꾼 뒤 복사해 사용합니다.

### 예제 모드

각 카드의 **예제** 버튼을 누르면 자리표시자가 실제 예시 값으로 채워진 상태로 열립니다.
모달 안에서 **원본 / 예제 적용**을 전환할 수 있고, 복사 버튼은 현재 보고 있는 모드의 텍스트를 복사합니다.

| 표시 | 의미 |
| --- | --- |
| 주황색 `[주제]` | 사용자가 채워야 하는 자리표시자 |
| 초록색 값 | 예제 모드에서 채워진 예시 값 |
| 예제 모드에서도 주황색인 `[확인 필요]` `[법무 검토 필요]` `[가설]` | AI가 출력에 남기도록 지시하는 마커. 사실 확인이나 전문가 검토가 필요한 지점을 표시하므로 채우지 않습니다 |

1,038개 중 1,001개에 예제 값이 들어 있습니다. 나머지 37개는 사용자가 채울 자리표시자가 없는 프롬프트로, 예제 버튼이 비활성 상태입니다.

## 로컬 실행

```bash
npm install
npm start
```

`http://localhost:3000` 에서 열립니다. 포트는 `PORT` 환경변수로 바꿀 수 있습니다.

```bash
PORT=8080 npm start
```

`index.html`은 정적 파일이라 서버 없이 브라우저로 바로 열어도 동작합니다. `npm start`는 배포 환경과 동일한 방식으로 확인하고 싶을 때 사용하세요.

## 구조

```
index.html   콘텐츠 · 스타일 · 스크립트가 모두 들어 있는 단일 파일
server.js    Express 정적 서버
package.json
```

프롬프트 데이터는 `index.html` 안의 `PROMPTS` 배열에 있습니다. 각 항목의 형태는 다음과 같습니다.

```js
{
  cat: 'mkt',                    // 카테고리 id
  title: '블로그 포스트 초안',
  desc: '검색 유입을 노린 블로그 글 구조',
  prompt: `당신은 ...`,           // 프롬프트 전문
  ex: { '주제': '뉴스레터 오픈율을 올리는 제목 쓰기' }  // 예제 값 (선택)
}
```

`ex`는 자리표시자 텍스트를 키로 갖는 맵입니다. 예제 모드는 `prompt` 안의 `[키]`를 이 값으로 치환하고, `ex`에 없는 자리표시자는 그대로 둡니다.

## 프롬프트를 쓸 때의 원칙

카탈로그에 포함된 프롬프트는 다음 기준을 지키도록 작성했습니다.

- 법률 · 세무 · 노무 관련 프롬프트는 `[법무 검토 필요]` 같은 마커를 남기고, 전문가의 조언을 대체하지 않는다고 명시합니다.
- 건강 관련 프롬프트는 진단을 내리지 않으며, 전문가를 찾아야 하는 시점을 함께 안내합니다.
- 이미지 프롬프트는 실존 인물의 초상과 특정 작가 화풍의 모방을 금지합니다.
- 마케팅 프롬프트는 수치 조작, 후기 조작, 허위 희소성 표현을 금지합니다.
- 개인정보를 다루는 프롬프트는 최소 수집과 동의 절차를 요구합니다.
